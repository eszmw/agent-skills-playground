| Requirement / LO evidence | Grader Test Type | MATLAB Grader UI fields | Code to paste | Expected evidence | Optional feedback on incorrect submission | Traceability |

| Build the humidity status message for its randomized count | Variable equals reference solution | Variable name: `humidityStatusMessage` | Not applicable | Matches the reference string scalar for the randomized humidity count | — | LO: adapt a string message to a numeric condition |
| Build the pressure status message for its randomized count | Variable equals reference solution | Variable name: `pressureStatusMessage` | Not applicable | Matches the reference string scalar for the randomized pressure count | — | LO: adapt a string message to a numeric condition |

The three direct-reference checks provide distinct evidence that each data set receives wording appropriate to its independently randomized count. Exactly one supplied count is one and the other two are greater than one.

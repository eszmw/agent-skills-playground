Vector Range Normalization

Write a MATLAB function that rescales a numeric vector so its values span the range [0, 1]. Range normalization is a common preprocessing step in data analysis and machine learning: it puts measurements with different units onto a common scale. After normalization, the smallest element of the vector maps to 0 and the largest maps to 1.

Instructions:
1. Create a function named vector_range_normalization that accepts one numeric vector x.
2. Find the minimum and maximum values of x.
3. Subtract the minimum from every element, then divide by the range (maximum minus minimum).
4. Return the result in xNorm without changing the orientation of x.

Required function signature:
function xNorm = vector_range_normalization(x)

Hints:
- min and max operate on an entire vector in a single call.
- Element-wise arithmetic on a vector does not require a loop.

You may assume x contains at least two distinct values.

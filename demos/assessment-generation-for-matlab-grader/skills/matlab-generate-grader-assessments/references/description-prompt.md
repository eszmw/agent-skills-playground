# Description generation prompt

Write plain student-facing text for a Script or Function assessment item. Include the learning task, exact required variables or function signature, observable expected outcome, and only constraints that the learning objective explicitly requires.

For formative use, include a brief non-answer-revealing self-check. For summative use, include no hints, self-checks, suggested functions, solution approaches, or answer-revealing implementation guidance. If the learning objective explicitly requires a function, construct, or approach, state it directly as a numbered requirement rather than presenting it as a hint. Explain mixed use only when the profile purpose is `both`; keep its formative guidance distinct from hidden summative details.

Do not mention Class or Object submissions.

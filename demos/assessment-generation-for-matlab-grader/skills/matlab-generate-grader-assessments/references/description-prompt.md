# Description generation prompt

Write plain student-facing text for a Script or Function assessment item. Include the learning task, exact required variables or function signature, observable expected outcome, and only constraints that the learning objective explicitly requires.

For formative use, include a brief non-answer-revealing self-check. For summative use, do not disclose hidden assessment details. Explain mixed use only when the profile purpose is `both`.

Do not mention Class or Object submissions.

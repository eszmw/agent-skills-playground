# Common Cartridge Export Rules

Use IDStack `course-export` for final `.imscc` generation. Treat Common
Cartridge as the persistence format for a MATLAB Course Designer course until
future API work can create course instances in the web application directly.

## Export Requirements

- Select IMS Common Cartridge, not Canvas API or SCORM, unless the user changes
  the deliverable.
- Export after course content has been generated by IDStack `course-builder`.
- Prefer running quality, accessibility, and red-team reviews before export.
- Preserve the `.idstack/project.json` manifest and `.idstack/course-content/`
  files that IDStack uses as source.
- Preserve the Course Designer hierarchy in the export source: course metadata,
  ordered modules, and ordered learning activities.
- Preserve only native Course Designer learning activity types: Reading, Video,
  MATLAB Exercise, and Simulink Exercise.

## Persistence Representation

The Common Cartridge should contain Course Designer-aligned content:

- Syllabus page
- Ordered module pages or module containers
- Ordered learning activity pages or resources
- Reading and Video resource pages
- Links or instructions for MATLAB Exercise and Simulink Exercise learning
  activities

The cartridge should not imply that a cartridge reader itself executes MATLAB
code, Simulink models, or MATLAB Exercise tests. Use explicit phrasing:

"Common Cartridge persists the course structure and instructions outside MATLAB
Course Designer. MATLAB and Simulink work is completed in the appropriate
MathWorks environment. MATLAB Exercise component parts are generated by
`matlab-create-course-activity`, which wraps `matlab-generate-grader-assessments`, validates generated `.m` files
with MATLAB MCP calls, then enriches the activity with Course Designer fields."

## Review Before Delivery

Before finalizing:

- Confirm the `.imscc` file exists.
- Confirm no unsupported learning activity types are present in the Course
  Designer structure.
- Confirm the instructor can locate source course content and activity briefs.
- Confirm `course-designer-structure.md` lists course metadata, ordered modules,
  and ordered learning activities.
- Confirm MATLAB Exercise folders, if any, include `matlab-generate-grader-assessments` component mappings
  and MATLAB MCP validation reports from `matlab-create-course-activity`.
- Confirm product requirements are documented in the course or checklist.
- Confirm deferred reviews are listed in the final response.
